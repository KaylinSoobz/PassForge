PassForge

Secure Password Generator

Create strong, unique passwords in seconds. Customize your password with different character types and choose the length that works for you. Whether you need a quick password for a new account or a stronger alternative to an old one.

About the Project

PassForge was built as a project to put my HTML, CSS, and JavaScript skills into practice by creating something practical from the ground up. The project uses JavaScript to generate customizable passwords based on the user's selected options, including password length, uppercase and lowercase letters, numbers, and symbols. I also implemented the interface and interactions myself using HTML and CSS. While building PassForge, I focused on improving my understanding of JavaScript functions, arrays, conditional logic, DOM manipulation, event handling, and user input. This project is part of my journey toward becoming a stronger developer — taking what I learn and turning it into functional projects.
